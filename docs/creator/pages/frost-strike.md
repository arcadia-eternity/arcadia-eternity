霜击命中后让对手的速度降低 25 点，持续两回合。把减速延长到三回合，再连续命中一次，验证目标只受一层减速。

## 打开示例项目

在桌面「内容包与创作」里新建一个资料包。也可以在「终端命令」复制创作命令，用下面的参数创建，再从工作台打开生成的目录。

```sh
arcadia-content init pack frost-pack
```

在项目里找到技能「霜击」和印记「减速」。项目自带的蓝队和橙队都能使用「霜击」和「轻触」。轻触不会施加减速，适合用来等待印记到期。

## 交给助手

打开项目的「AI 助手」，勾选「允许运行测试、演示对战和打包」。复制连接提示词到本机 AI 客户端，等它通过 `workspace_describe` 确认项目目录，再发送下面的请求。

```text
把霜击的减速延长到三回合。再次命中时刷新到三回合，速度总共只降低 25 点。
请更新并运行模板测试，告诉我首次命中、再次命中和到期时各发生了什么。
```

助手可以先用 `content_query` 搜索「霜击」，沿[技能的行为引用](./api/skill-behaviors.md)找到[命中效果](./api/on-hit.md)。工作台里如有尚未保存的编辑，先核对草稿和磁盘上的版本。

## 核对改动

打开 `data/marks/slow.yaml`，核对[印记的持续时间与刷新策略](./api/mark-duration.md)。把文件顶部注释中的两回合也改成三回合。

```diff
 config:
-  duration: 2
+  duration: 3
```

保留一层上限、刷新策略和[速度绑定](./api/bind-attribute.md)。在 `test/pack.test.mjs` 里检查**两个观察时点**：

| 时点                             | 预期                                                                   |
| -------------------------------- | ---------------------------------------------------------------------- |
| 首次命中、以及剩一回合时再次命中 | 命中效果刚结算时剩余 3 回合，只有一枚印记、一层减速，速度为原速减 25。 |
| 从等待点快照恢复，再连续使用轻触 | 恢复时剩余 3 回合。往后每回合结算后的读数为 2、1、0，归零时速度恢复。  |

快照用例会把速度参数临时调成 −30，用它验证参数恢复；保留这个独立断言。助手运行 `test_start` 后，用 `job_get` 确认测试成功且结果对应当前源码。参见[测试与试战](./api/battle-test.md)。

## 亲自试玩

保存项目，重新准备试玩，选择项目队伍 `blue` 和 `orange`。在蓝队第一次命中前记下对手速度，依次使用 **霜击 → 轻触 → 霜击**。比较两次霜击后同一回合阶段的读数：第二击延长了减速，速度降幅依然是 25 点。接下来连续使用轻触，直到印记消失，再核对原速。

想让助手解释某一行，可以直接问「为什么绑定的速度在印记消失时会恢复？」。当前 SDK 支持精确查询时，它可以通过 [author_reference](./api/author-reference.md) 读取 `ops.bindAttribute`。
