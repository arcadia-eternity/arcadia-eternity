第一次打开工作台，先用自带的霜团打一场。成功的标志是能选中霜击，看到对手获得减速，随后用轻触等到印记消失。这个起点同时适用于用表单创作、自己写代码和使用 AI 助手的人。

还没有工作台时，从[项目发行页](https://github.com/arcadia-eternity/arcadia-eternity/releases)选择对应系统的桌面安装包。打开客户端后进入「创作工坊」。桌面新建项目会连接随应用提供的创作 SDK。

## 选哪一种项目

| 你想让玩家体验什么                       | 创建什么 | 第一个可以玩的结果                                                         |
| ---------------------------------------- | -------- | -------------------------------------------------------------------------- |
| 一只精灵、一招技能或一种新印记           | 资料包   | 霜团在技能栏里使用你制作的招式                                             |
| 用已有精灵办比赛，规定队伍人数或可用内容 | 独立环境 | 两支合规队伍按你的规则开局。直接进入[单精灵杯教程](../make/singles-cup.md) |

## 创建并打开资料包

在桌面客户端「创作工坊」创建资料包，命名为 `frost-pack`。也可以在「终端命令」复制本机创作命令，把末尾的 `--help` 换成下面的参数，然后在工作台打开生成的目录。命令中的 `arcadia-content` 代表客户端显示的完整路径。

```sh
arcadia-content init pack frost-pack
```

在项目内搜索「霜团」，打开精灵的可学习技能，找到「霜击」和「轻触」。一个项目包含中文显示名、稳定 ID 和战斗规则；后文均使用同一个模板，可以对照自己项目中的对象。

## 打第一场

点击「调试试玩」，用项目自带的 `blue` 和 `orange` 队伍开始对战。第一位玩家由你操作。先选霜击，命中后检查对手的减速印记。随后使用轻触，观察回合推进；轻触本身不会给对手续上减速。你现在有了一场可用于比较的原版对战。

改完规则后，先保存源码，再重新准备试玩并开一局。已经开始的对局继续使用开局时的内容。
