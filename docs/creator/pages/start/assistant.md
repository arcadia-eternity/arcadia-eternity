打开可编辑项目的「AI 助手」，把本机 AI 客户端连接到这个目录。助手和你会看到同一份已保存的项目源码。

## 接好连接

1. 只需查询时，使用当前连接提示词。需要测试或试玩时，先勾选执行选项，再复制提示词。
2. 把提示词粘贴到 AI 客户端的项目对话，按提示载入配置。让它调用 `workspace_describe`，核对返回的项目目录和会话能力。
3. 回到工作台选中霜击，让助手读取 `workspace_context`。桌面连接会带上当前对象、内容语言和草稿状态。直接从终端启动的独立 MCP 连接可能没有这份界面上下文。

## 发出第一项任务

```text
在当前项目里找到霜击和它施加的印记。告诉我哪个文件决定持续时间，
哪个效果决定速度降幅，并附上你实际查到的 ID。先只读取。
```

你应该能对上三个名字：技能 `strike`、命中行为 `apply-slow` 和印记 `slow`。接着可以请助手改一条具体规则，并写出怎样判断它生效。已有[完整的霜击请求和验收步骤](../frost-strike.md)。

## 一次编辑怎样落到文件

助手用 `content_query` 定位对象，以 `detail: "full"` 取得原记录和版本，再保存修改。表单中有未保存值时，先在工作台核对草稿，决定本次要保留哪些值。磁盘上的版本发生变化后，重新读原文件并合并修改。

已安装依赖可以作为参考。要修改依赖里的机制，需要打开它的可编辑源项目，或者在自己的包中创建独立内容。连接后只有读取能力时，先看 `workspace_describe` 返回的项目与权限。

## 找到与本机版本一致的做法

让助手读 `author_reference` 的主题，再用条目返回的 `symbol` 精查。例如 `{"topic":"effects","symbol":"EffectTrigger.OnHit"}`。旧 SDK 如果只接受 `topic`，仍可以使用主题示例。未连接工作台的助手也可从[网站 Markdown 索引](https://battle-docs.yuuinih.com/llms.txt)选页。参见[查询和保存项目内容](../api/workspace.md)。
