想在自己的对战环境里长期使用作品，先生成可安装的版本，再把它加入目标环境。创作项目可以继续编辑；玩家安装的版本有自己的包版本和完整性信息。

## 在工作台使用当前包

1. 保存源码和表单草稿，运行场景测试。
2. 构建内容包，选择「用于环境」，选中本机目标环境。改版后可用「重新构建并用于环境」。
3. 在目标环境保存并应用配置，打开队伍编辑器，搜索这个包的新精灵或技能，再开始一场新对战。

如果试玩窗口有霜团而玩家的队伍编辑器里没有，核对当前选中的环境，以及该环境实际使用的包版本。

## 给另一台客户端安装

在资料包源项目中执行发行检查，或在工作台选择「检查并生成发行包」。

```sh
arcadia-content workspace . release --execute
```

保存任务给出的 `.tgz` 文件名、文件清单和 SHA-512。归档用于安装。协作者要改源码时，请分享源项目或 Git 仓库。

保持接收方的桌面客户端打开，在接收方机器上用其创作命令安装。将 `./my-pack.tgz` 换成上一步实际生成的路径。

```sh
arcadia-content desktop instances
arcadia-content desktop packages install ./my-pack.tgz
arcadia-content desktop packages list
```

多个客户端同时运行时用 `--instance` 指定实例。安装后，在目标环境选择该资料包并应用；用新开的一局检查内容。要让别人从公开地址安装，继续[发布作品版本](./release.md)。

## 在多人服务器上使用

本机环境用于自己的离线试玩。要让其他玩家在同一台社区服务器使用作品，服主需要在服务器工作区准备包含该包的环境，并把准备好的版本绑定到服务器。让服主核对包版本、环境修订和第三方效果执行策略。官方服务仅运行其准入的内容。玩家在自己的资料库安装成功，只能证明这个包已经进入本机库。
