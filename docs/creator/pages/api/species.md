**源文件**　`data/species/*.yaml`。物种定义描述所有该物种共享的属性。队伍里某一只精灵的等级、性格、个体值和实际配招记录在[队伍文件](./team.md)。

| 字段                                        | 读取与修改                                                                                   |
| ------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `id`、`num`、`element`                      | 稳定的局部 ID、图鉴编号和属性。其他对象通过稳定 ID 引用。                                    |
| `baseStats`                                 | `hp`、`atk`、`def`、`spa`、`spd`、`spe` 分别为体力、物攻、物防、特攻、特防、速度的种族值。   |
| `ability`、`emblem`                         | 特性和纹章的引用。模板的空数组表示未配置。                                                   |
| `learnable_skills`                          | 每项包含技能引用 `skill_id`、学习等级 `level` 和 `hidden`。`skill_id.$ref.kind` 为 `skill`。 |
| `genderRatio`、`heightRange`、`weightRange` | 性别比例、身高和体重范围。创建时可沿用模板的有效值，再按设定调整。                           |
