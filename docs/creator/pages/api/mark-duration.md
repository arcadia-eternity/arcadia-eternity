**适用位置**　内容包源文件 `data/marks/*.yaml` 的 `config`。

| 字段                         | 减速印记中的作用                                                 |
| ---------------------------- | ---------------------------------------------------------------- |
| `duration`                   | 模板初值为 2。教程改为 3，表示命中施加时的剩余回合数。           |
| `stackable`、`stackStrategy` | 模板使用 `true` 和 `refresh`，再次施加会刷新既有印记的持续时间。 |
| `maxStacks`                  | 模板上限为 1，连续命中时仍为一层。                               |
| `persistent`                 | 模板值为 `false`，允许按回合倒计时、自然到期。                   |
