**源文件**　`data/skills/*.yaml`。没有特殊机制的技能可以只用数据定义。下面的「轻触」是模板里可直接运行的例子。

<<< data/skills/rest.yaml

| 字段                  | 模板中的意义                                                               |
| --------------------- | -------------------------------------------------------------------------- |
| `id`                  | `rest` 是局部 ID，语言文件、表现绑定和技能表都用它找到这招。               |
| `element`、`category` | `Normal` 是普通属性，`Physical` 是物理类别。编辑器的候选项与本机版本匹配。 |
| `power`、`accuracy`   | 轻触威力为 1、命中率为 100。威力参与结算，不能直接当最终伤害。             |
| `rage`                | 怒气消耗，模板值为 0。                                                     |
| `behaviors`           | 为技能增加特殊机制。每次绑定指定自己的 `useId` 和效果引用。                |

要增加一个同类技能，可以从这个最小定义起步，使用独立的 ID，并在语言文件里添加显示名。要给它附加印记时，再读[行为绑定](./skill-behaviors.md)和[命中回调](./on-hit.md)。
