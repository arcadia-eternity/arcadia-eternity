# UGC 领域词汇

本词汇表限定作品创作、分发和对战使用中的概念。完整设计与实施范围见[统一作品模型、三级 UGC 与创意工坊设计](../ugc-design.md)。

## 作品与使用

**作品（Project）**：作者维护的一组关联精灵、技能、印记、行为和素材，具有持续的作品身份。
_Avoid_：用文件夹或安装目录代指作品。

**草稿（Draft）**：作品的可编辑状态，可以包含尚未完成的内容。
_Avoid_：把保存成功称为可运行。

**作品版本（Release）**：作品经校验后形成的固定内容及其精确依赖，可以保存在本地或用于分享。
_Avoid_：把生成版本等同于公开发布。

**本地工作区（Workspace）**：某台设备或浏览器资料中管理草稿、已安装作品与个人使用选择的空间。
_Avoid_：把本机启用状态称为作品属性。

**内容组合（Content Composition）**：为一次试玩或房间明确选择的作品版本、基础内容和规则配置。
_Avoid_：整个本地作品库。

**对战环境（Battle Environment）**：根据内容组合及获准能力确定、在对战期间保持固定的完整规则环境。
_Avoid_：房间同步包、全局可变内容库。

**精灵定义（Species Definition）**：描述某种精灵的基础属性、技能和外观的可分享内容。
_Avoid_：个人宠物、战斗中的精灵实例。

**个人宠物／队伍配置（Owned Pet／Pet Build）**：玩家对精灵的培养和选用配置，引用作品中的定义。
_Avoid_：种族定义、作品本身。

## 行为与创作

**行为定义（Behavior Definition）**：作品层具有身份、公开参数和适用条件的可复用效果，对应现有效果定义的创作表示。
_Avoid_：某一次技能使用中的可变状态。

**行为使用（Behavior Use）**：技能或印记对一个行为的独立引用，具有自己的参数配置，对应现有效果配置中的一次使用位置。
_Avoid_：与另一处引用默认共享参数。

**预设（Preset）**：通过有限公开参数供作者使用的行为定义，可由组合规则或原生能力提供。
_Avoid_：只能复制的一段编辑器文本。

**效果来源（Effect Source）**：承载一次效果执行及其本局状态的具体技能或印记实例。
_Avoid_：共享的行为定义或预设。

**规则组合（Rule Composition）**：使用受支持能力表达触发、条件、概率和有序动作的行为。
_Avoid_：任意可执行表达式。

**扩展（Mod）**：为作品提供额外原生行为或可组合能力、需要独立安装和准入的代码内容。
_Avoid_：普通作品导入即自动获准执行的附件。

**三级创作**：配置预设、组合规则和编写扩展三种可共同用于同一作品的创作深度。
_Avoid_：互斥作品类型、代码信任等级。

## 分发与准入

**作者声明**：作品中由提供者填写的创作署名及来源说明。
_Avoid_：经验证的发布者身份或所有权证明。

**发布者**：在某个分发服务中经过该服务身份验证、执行发布操作的主体。
_Avoid_：仅凭自报 UID 认定的作者。

**创意工坊（Workshop）**：提供作品介绍、固定版本发布、发现和下载的分发入口。
_Avoid_：房间内资源同步、必需的本地创作账号。

**对战准入（Battle Admission）**：运行方对某个固定内容环境是否允许用于对战的决定。
_Avoid_：作品公开可下载就自动允许官方对战。

**环境一致性**：参与同一对战的客户端与权威运行方使用同一选定规则环境。
_Avoid_：双方整个作品库或队伍内容完全相同。
