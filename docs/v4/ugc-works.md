# UGC 作品、命名空间与本机创作

UGC 面向内容创作：玩家设计精灵、技能、印记，组合已安装的效果模板。新的机制继续由可信 TypeScript 实现；作品文件不能安装或执行代码。模板目录见 [UGC 效果目录](./ugc-effect-catalog.md)。

## 身份与引用

运行时内容 ID 采用 `namespace:id`，例如 `frost_pack:skills/ice_strike`。

- `namespace` 属于作品，使用小写字母、数字、点、下划线、短横线，长度 1–80；`base` 保留给官方内容。
- 局部 `id` 使用相同字符并允许 `/` 分段，长度 1–120。空路径段、`.`、`..`、冒号、大写不合法。
- 类型在目录和引用中表达，不在 ID 中强制加入类型段。`skills/` 只是作者可选的组织方式。技能与印记可以各有一个 `frost_pack:ice`。
- 同一个运行环境只能有一个作品占用某个命名空间。安装同名空间作品可以成功，启用时必须解决冲突，不能靠加载顺序覆盖。
- 作品还有独立的稳定 `project.id`。显示名称、命名空间与作品身份不是同一字段。

草稿与发布源数据保存局部 ID；作品内/跨作品引用使用明确的结构，例如：

```json
{ "$ref": { "projectId": "stable-project-id", "kind": "mark", "id": "slow" } }
```

编译时根据所选作品把这个引用解析为 `frost_pack:slow`。编辑器展示完整 ID，作者不用手写结构。跨作品引用必须声明直接依赖的精确版本和摘要；不会因同名空间而自动认领另一个作品。

现有官方内容仍保留 `skill_paida`、`mark_*`、`base/template/*` 等旧 ID。普通字符串引用限于官方目录；新作品引用使用上述结构。兼容适配避免一次性破坏已有队伍、效果内的固定引用和重播。

另存副本生成新的作品身份和命名空间，重定向结构化的内部引用，保留外部依赖与说明文字。含自定义原生行为导出的作品不能自动分叉，需由开发者核对 TS 内的固定引用。

## 草稿、固定版本与环境

`packages/pack-loader/src/works` 提供不依赖 Vue、Node 文件系统或数据库的模型、校验、编译、分享格式与作品库操作。

1. **草稿**可以保留未完成的记录。保存只校验数据结构和 ID，不声称内容可以运行。
2. **固定版本**校验记录、行为参数、引用、原生能力、依赖和素材字节，经过真实内容工厂验证后生成 SHA-256 摘要。同一作品同一版本不能用不同内容替换。
3. **环境**只包含显式选择的固定版本及其依赖闭包，拒绝缺失依赖、版本冲突、循环及命名空间冲突。可信引擎/效果构建、基础数据、能力许可和选定版本共同进入环境摘要。
4. 运行环境捕获自己的数据和内容目录。编辑草稿、安装未启用作品不会修改正在运行的战斗。

当前依赖必须指定完整版本，例如 `1.0.0`，并绑定摘要；尚未提供版本范围解析器。作品不支持覆盖官方对象。

## 本机使用

打开导航中的 **创作工坊**（`/creator`）：

- 创建作品并指定命名空间；新增精灵、技能、印记，或复制官方内容作为起点。
- 为技能/印记添加效果模板，配置参数及印记引用；为精灵配置种族值、可学技能、特性和纹章。
- 保存草稿；校验并准备试战会固定草稿快照。试战使用真实 V4 引擎，100 级镜像对手和前四个可学技能，可观察生命及印记变化。
- 创建固定版本后导出分享。启用列表决定额外加入试战的固定版本，也可整体导出为组合文件。
- 导入先展示数量再入库；不会覆盖已有草稿，也不会自动启用作品。

浏览器和静态站点使用 IndexedDB；Electron 使用用户数据目录的 `creator-works/works.json`。浏览器事务与 Node 文件锁/原子替换提供作品库级比较并交换；草稿还有自身修订号，旧窗口保存会报告冲突。

关闭页面前需要保存草稿。当前复制官方内容保留其官方效果和原有引用；不会猜测重写 TS 内部机制。

`.arcadia` 是有大小限制的 JSON 作品文件，包含草稿或固定版本、依赖及声明的素材字节。它不包含脚本、压缩路径或运行时实例。素材支持 PNG/JPEG/WebP、Ogg/MP3 清单与字节摘要校验；当前编辑器使用官方外观编号，尚未接入自定义素材上传和呈现。

命令行加载发布文件：

```sh
pnpm cli content validate --works example.arcadia --json
pnpm cli battle simulate -1 first.json -2 second.json --works example.arcadia --replay-out replay.json --json
pnpm cli battle replay replay.json --verify --json
```

队伍中的精灵和技能 ID 使用编译后的完整 ID。重播携带基础数据、选定发布版本及依赖；重播宿主重新编译并比对环境身份，不能只相信文件自报的摘要。

## 后续集成边界

本地客户端创作试战通过一次性会话进入普通本地对战配置页和完整战斗界面；网页端创作入口保持只读。草稿、临时队伍和展示覆盖的生命周期见 [本地试战生命周期](./local-trial-lifecycle.md)。CLI 加载/重播和 Electron 作品库接口继续复用；仍需桌面打包后的验收，以及普通队伍编辑的作品选择入口。私人房间的作品环境匹配、服务端准入、官方创意工坊、分享链接、素材呈现和版本范围解析继续单独推进；当前不会在房间内下载或同步作品，也不自动让公共匹配接纳自定义内容。
