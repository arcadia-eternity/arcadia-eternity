# UGC 工作台与作者工具链

当前作者流程以标准 npm 源项目为中心。桌面工作台、作者 CLI、MCP 和外部编辑器共同编辑源文件；安装版本与对战环境另行准备。操作入口见[作者入门](ugc-authoring-start.md)，工具实现见 [content-dev](../../packages/content-dev/README.md)。

## 职责

| 入口             | 当前职责                                                                           |
| ---------------- | ---------------------------------------------------------------------------------- |
| 桌面内容包工作台 | 创建／打开源项目，编辑精灵、技能、印记、资源、表现及语言；只读浏览基础包与安装产物 |
| Effect SDK       | TypeScript 效果、领域对象、参数、生命周期与真实引擎测试                            |
| 作者 CLI         | 共用校验、构建、打包、工作区读写和场景任务                                         |
| MCP              | 查询项目与当前工作台上下文，按版本读写源码，调用共用作者任务                       |
| Agent Skill      | 指导外部编码助手查询、修改、诊断和验证内容                                         |

工作台不直接调用模型。代码和原始文件整理使用外部编辑器；新机制使用 TypeScript。模板通过原生行为工厂复用。

## 对象、资源与保存

源文件按稳定内容 ID 关联。规则、资源定义、表现绑定和语言分别维护；资源使用稳定软引用，格式见[内容表现](content-presentation.md)。

新建对象和关联先进入草稿，审阅后保存；资源导入立即复制文件，资源定义与表现关联进入草稿。基础包和安装版本只读。切换对象或语言保留未保存草稿，查看位置不构成作者工具的授权范围。

CLI、MCP 与桌面共用结构化保存逻辑。同一文件的变更合并写入，多个文件逐个提交；部分失败时保留剩余草稿。外部变化触发原值／草稿／最新值核对，核对后仍需保存。来源缺失、重复或无法确认时暂停写回，唯一来源移动后可经核对采用新位置。YAML 锚点、别名和继承字段只读；独立字段与显式覆盖值可编辑。

写入格式、版本检查及 YAML 合同见 [content-dev](../../packages/content-dev/README.md#object-drafts-and-reviewed-saves)。

## 上下文与任务身份

MCP 的 `workspace_context` 可读取包、查看位置、对象或资源、语言、未保存草稿和冲突。上下文写入 Electron userData 的临时文件，关闭时清除，失去心跳后过期。源码查询仍读取磁盘版本，写入仍检查文件版本；未保存内容不会替换运行中的版本。

源修订、打包摘要、安装目录、环境身份和任务状态分别记录。保存源文件后需要构建、检查和准备新的候选。任务结果保留其输入身份，过时结果不能冒充当前草稿的验证结果，活动对局继续使用原环境。候选流程见[开发预览](development-preview.md)和 [npm 环境](npm-content.md)。

## 验收与后续工作

`demo` 运行无界面真实引擎任务。工作台的“准备画面试玩”、CLI `workspace <项目> preview --execute` 与 MCP `preview_start` 共用候选流程：复制已保存源码、构建并打包、隔离安装，再启动仅监听本机的 Node 试玩宿主。任务返回战斗客户端地址；工作台可直接打开独立试玩窗口。效果留在 Node，窗口只消费公开定义、按需素材和战斗消息。

候选保留输入源修订和包身份。源码改变后，已有战斗继续运行原候选；旧任务明确标记过时，仍可选择“打开旧候选画面”。新候选失败或取消会保留旧候选。任务记录存于项目 `.arcadia/author-jobs`，桌面、CLI 与 MCP 可查询和取消同一个任务；宿主异常退出后标记 interrupted，需重新运行。候选运行进程和临时安装不会作为跨重启存档保留。
