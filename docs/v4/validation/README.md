# 固定回归数据

本目录保留测试使用的 candidate 定义、原始来源/修正记录及历史审计 JSON。测试会直接读取文件，也会按文件名拼接或遍历；清理时需检查动态读取，不能只按文本引用数量判断是否可删。

这些记录固定了历史比较输入。当前官方行为维护在 `packs/base/src/effects/`，元数据由基础包 manifest 选择；更新行为应修改 TS 和对应回归，不从记录反向生成或覆盖已审阅代码。E/C/U 与候选覆盖率不等于最终验收状态。

内容与行为约定见 [V4 指南](../direct-v1-port.md)。运行结果由当前测试和 CI 给出，旧日志、逐批进度与审查过程从 Git 历史查询。
