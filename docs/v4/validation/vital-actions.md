## Indexed dynamic multiplication

Two additional candidates bring the catalog to 32 emitted, 18 rejected and 27 retained definitions. The niliu heal divides maximum HP by 16 and floors before multiplying by the first matching niliu stack. The zhongzinengliang heal divides damageResult by 4 and floors before multiplying by the first matching seed-energy stack. The first effect requires niliu at collection; the second has no mark-existence gate.

The numeric multiplication emitter uses the existing values.combine API. It evaluates the left query then the right collection, pairs by index and uses zero for missing factors. A scalar consumer takes the first left result and first factor; multiple matching marks are neither summed nor broadcast. This explicitly matches the numeric legacy combine path, not the separate Observable multiply default of one. No runtime implementation changes are included.

All 1,081 single-vital public checks pass. Independent cases cover no support, zero/one/three stacks, reversed duplicate-mark stacks [2,7]/[7,2], a 2015 maximum HP and 103 damageResult to distinguish floor-before-multiply, late removal and late changes to both dividend and stacks. The generator execution check also covers multiple left values, shorter right lists, and evaluating the RHS when the LHS collection is empty. All previous records and catalogs reproduce unchanged.
