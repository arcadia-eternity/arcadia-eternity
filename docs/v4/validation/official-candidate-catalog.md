# Official candidate assembly

`createOfficialEffectCandidates(marks)` assembles the native candidate factories, returns their effect IDs, owning families and parameter catalogs, and rejects unexpected duplicate IDs or missing canonical mark dependencies. The authored illusion-consumption example explicitly owns its existing generated duplicate. Water-shield destruction uses the caller's amplification prototype.

The catalog neither mutates mark effect lists nor admits candidates into production. The current pack loader still imports V2 runtime/parser types; switching it to V4 requires a host migration, not a parser substitution. Missing candidates have no automatic legacy fallback.

Validation: 268 tests across the catalog, water-shield content, shield parameters, named parameters, random temporary effects and rain-water shield. Catalog checks compare its complete ID set with the independently read migration ledgers, verify canonical prototype identity through actual mark destruction and install parameter catalogs in isolated battle configurations. The existing shield damage fixture now explicitly requests Physical damage, matching its shield-absorption assertions; Effect damage intentionally bypasses shields.
