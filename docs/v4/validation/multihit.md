The authoring API reuses the skill numeric operator helper. addMultihitResult reads separately for each selected context and adds every value in order, without rounding or clamping. setMultihit also reads separately per context but assigns only the first scalar value; an empty selection leaves the initial count unchanged. This API currently covers scalar counts and queried numeric collections. Tuple interval declarations are not accepted by this generator and are not confused with a collection of independently selected numbers.
