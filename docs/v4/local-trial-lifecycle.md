# 本地对战与作者预览生命周期

普通桌面本地对战从 ContentLibrary 最近成功准备的组合取得内容，个人队伍编辑使用同一组合的展示数据。沙箱执行与展示捕获相同内容版本；目标准备中或失败时，仍使用最近成功组合。初次空包库直接使用官方基础内容，不将未完成目标当作可开局内容。

## 普通本地对战

进入普通本地配置页时捕获组合并持有展示与资源租约，开局捕获双方队伍和运行参数，创建独立沙箱战斗实例。之后切换启用包只影响重新打开的配置，不修改当前配置或对局。启动失败释放实例，配置保留同一组合供重试；离开配置、取消或战斗清理时释放展示和租约。旧异步结果不能覆盖后来创建的对局。普通本地对战不启动联机托管服务。

成功组合的目录回收必须保护已安装内容、当前可用组合、准备中的组合、所有房间引用和本地租约。已有房间和本地对局释放之前，不能因新的内容选择删除其运行内容。

## 作者调试

作者从源码工作区准备候选，在独立调试窗口选择项目队伍、参数并开局。预览使用绑定候选的执行与展示数据，队伍通过项目队伍库保存；返回编辑器保留编辑位置。替换预览会关闭旧窗口并释放旧宿主和候选会话，项目文件及本机队伍草稿继续保留。

作者预览不再使用旧的一次性 trial tickets，也不经过玩家 `/local-battle` 配置入口。项目队伍、环境和自动用例合同见 [项目队伍与对战环境](./project-battle-workflow.md)。

## 验证范围

自动化检查应覆盖组合固定、准备失败保留旧组合、启动取消、重复清理、旧异步响应、展示与执行一致以及租约释放。作者预览另检查替换窗口、项目队伍恢复及退出清理。实际发布仍需完成签名安装包在目标平台上的窗口、资源播放、安装与重启验收；实现合同不代表这些平台验收已经完成。
