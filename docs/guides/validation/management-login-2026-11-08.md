# 管理后台与登录验证（2026-11-08）

## 实现范围

- 后台使用独立全页布局，隐藏游戏导航；顶部仅保留服务器、管理身份和操作，左侧为功能导航，移动端可折叠菜单。
- 主导航入口以服务端确认的管理权限为依据；未登录用户通过服务器页“更多 → 管理员登录”或 `/management` 访问登录页。本机管理继续使用可信 IPC。
- 栏目写入 URL，刷新、前进后退可恢复栏目，不重建整个后台。无权访问的栏目回退到可用栏目。
- 自动恢复管理会话、已记住设备或已授权 G3 账户。主动退出后保留标签页级退出选择，避免立即自动重新登录。
- G2 支持用一次性码完成首次设置，再登记通行密钥；可选择记住设备 30 天。密钥和设备可撤销，关联会话随之失效。

## 自动验证

服务端执行 `managementAuth`、`managementLogin`、`management`、`managementAccounts`、`managementTransport` 五个测试文件：51 项通过，7 项 PostgreSQL 用例因未配置 `TEST_DATABASE_URL` 跳过。

验证使用实际 SQLite 存储、真实 HTTP 请求，以及真实 ES256 签名与 WebAuthn 验证器，覆盖：

- 随机/篡改 token、数据库摘要冒充 token、无签名管理员声明、伪造 UID/角色请求头、游客 token 均不能读取或操作管理资源。
- 普通账户必须显式关联和授权；停用账户、撤销授权后不能继续执行受保护操作。
- 通行密钥验证签名、站点、挑战、用户验证标志；挑战只用一次，登记挑战绑定管理会话，过期挑战和服务 token 登记被拒绝。
- 限权会话登记密钥或记住设备不会提升权限。
- 长期凭证原子轮换、固定到期、旧值拒绝、退出撤销及派生会话失效；数据库不保存明文凭证。
- Cookie 写操作保留 Origin 与 CSRF 检查。无保存凭证的自动检查不消耗主动登录限流额度。

前端管理组件、管理客户端和自动会话恢复测试：115 项通过。服务器、根工作区和前端类型检查，以及修改范围的 ESLint 检查通过。服务器、CLI、前端生产构建通过。

## 浏览器验证

使用临时 G2 服务器、隔离数据目录和 Chromium，在 1440×1000 与 390×844 视口验证：

1. 未登录时主导航无后台按钮；服务器页更多菜单能进入管理员登录页，G2 不显示不可用的玩家账户登录。
2. 登录码首次进入，并选择记住设备。
3. 使用 Chromium 虚拟认证器登记通行密钥，退出后通过该密钥重新登录。
4. 刷新恢复管理会话；仅删除短期会话 Cookie 后，自动使用长期凭证恢复并轮换。
5. 登录后主导航显示后台入口，直接进入，无重复授权按钮。
6. 手机菜单可展开和切换；栏目 URL 更新，页面无横向溢出。

本次未验证 PostgreSQL、真实硬件认证器、各平台已安装 Electron 应用或生产 HTTPS 部署；上述浏览器验证使用 localhost 与 Chromium 虚拟认证器。
