# 源项目候选画面试玩验收（2026-11-01）

对应 #223／#244。实现提交 `3dbe3853`，生命周期与跨入口修正 `3b44786c`、`21ead887`；集成分支为 `refactor/v4`。

## 已验证流程

- Electron 源项目工作台编辑并保存技能、名称与印记，运行该项目真实 npm 产物的四个行为场景；准备同一源修订的候选，在独立窗口进入现有完整战斗页，实际点击技能直到胜负。画面覆盖包内形象、技能描述、伤害、印记、KO 与战斗记录，窗口没有 `arcadiaDesktop` 管理接口。
- 离开源项目编辑页后，独立试玩继续运行；刷新试玩窗口后，双方、回合、HP 和运行状态与刷新前一致。返回工作台可继续编辑。
- MCP 按版本写入错误源码，读取文件／行诊断，再读写修复、检查、运行真实测试和 `preview_start`；测试与预览的源修订及实际 npm 包身份一致。桌面／CLI 能查到同一任务。
- 新候选编译失败或取消时，旧候选与旧对局保持；修改源码并准备新候选后，新旧候选分别保留各自威力数据。旧候选显示为过时，仍可显式重新打开。
- CLI 取消 MCP 所有的试玩，以及其他会话取消 CLI 所有的试玩均通过；CLI 正常输出最终取消状态并退出。强制结束 CLI 所有者后，子进程退出，新会话显示 interrupted，源项目保留。
- 玩家配置省略 ID 时能生成身份并进入试玩；完成历史超过 30 项仍保留活动候选查询；并发清理历史不打断查询；收据写失败不启动任务；请求失败后可重新开始轮询；初始化或导航失败会清空本次战斗接口并恢复展示数据。
