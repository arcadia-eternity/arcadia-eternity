# 网页、桌面与服务器的内容边界

2026-10-29 的产品约束，实施索引为 [#254](https://github.com/arcadia-eternity/arcadia-eternity/issues/254)。本文约定目标行为；具体平台的验证结果由各实施 issue 记录，不将设计约束当作已完成的安全验收。

## 配套网页与桌面连接

浏览器网页由部署配置固定配对一个服务器。官方网页可以继续与后端分开托管，自托管发行物默认提供配套网页；前后端代码或进程分离不影响产品配套。浏览器地址参数、选服历史和邀请链接不能覆盖部署绑定。部署可以显式选择独立前端或 headless 模式。

桌面客户端允许选择第三方服务器，使用客户端自带的游戏界面。进入第三方服务器不意味着安装其 npm 包、执行其 TypeScript、启动本地主机或授予工作区文件权限。本地管理与远程游玩拥有不同权限；既有可信创作、离线试战和显式联机托管继续保留。

## 固定对战协议

对战消息、状态与可选操作由核心定义。UGC 可以新增精灵、技能、印记和服务端规则实现，但必须通过现有协议表达结果。UGC 不注册客户端消息处理器、组件、渲染器代码或新的交互类型。

服务端规则负责计算，客户端依据公开状态和结算事件显示。表现回调不决定命中、伤害或胜负。现有协议不能表达的需求交给核心评估，不通过资源包下发脚本补齐。

## 环境资源包

内容包仍是作者发布、服主安装和依赖管理的单位。作者可以在同一项目维护资源与逻辑，构建和环境准备时分离客户端所需的公开数据。

| 内容                                 | 来源与消费者                                     |
| ------------------------------------ | ------------------------------------------------ |
| 效果、规则代码及执行依赖             | 服务器安装并运行                                 |
| 名称、描述、语言、公开属性和表现配置 | 从当前服务器的固定环境取得，客户端按核心结构解释 |
| 实时公开数值与战斗结果               | 既有对战协议                                     |
| 图片、音频和 SWF 文件                | 当前环境声明的资源入口，使用时取得               |
| 界面组件、事件解释和播放器实现       | 随客户端发布                                     |

玩家进入服务器后先确定环境、加载并验证公开目录，再基于该目录组队和入局。资源包是清单与文件的逻辑集合，不要求 ZIP、全量下载或客户端 npm 安装。客户端不以本地是否安装同名代码包作为远程游玩的前提。

内容查询必须包含服务器、环境与内容身份。目录涵盖该环境需要的官方和自定义内容；缺少必要定义时明确失败，不静默使用另一服或客户端本地的同名定义。语言资源只能作用于内容命名空间，不能改写应用登录、权限或管理界面。

目录就绪、核心协议/展示能力兼容、媒体实际加载是不同状态。非必需媒体可以降级，不能把读取索引报告为全部素材播放成功。活动对局固定原环境，更新供新环境使用；切服、取消和退出后的迟到响应不得覆盖当前状态。

## 资源访问和 SWF

UGC 素材不建立共享、磁盘或代理缓存，不预取全部素材。按需取得，使用结束释放。HTTP(S) 外链只固定引用，不保证源站字节不变；摘要和大小声明不是安全认证，实际输入仍需限额和校验。

SWF 是可执行媒体。保留原作素材和必要的动画脚本，但将整个播放器页面作为不可信环境处理。服务器认可素材不授予素材访问玩家账号、业务页面、桌面接口或任意网络的权限。这替代此前“服务端可信 SWF 无需额外播放器隔离”的约定。

浏览器和桌面共用有限播放语义：加载获准素材、播放既有状态、设置显示参数、停止和释放；返回就绪、状态列表、命中时点、完成和错误。接口不接收任意函数名、脚本、HTML 或代理 URL。消息校验实例、任务归属、类型、长度、频率及生命周期。

浏览器采用受限 iframe；桌面采用独立低权限播放环境。两种载体分别验收来源、网络、导航、存储、原生权限和故障恢复。Ruffle 内部配置不能替代外层限制，iframe 不能被当作独立进程或硬资源上限。实际依赖版本、容器加载子影片的兼容性、恶意样例与超时恢复必须记录实测证据。

桌面播放器离屏运行，由主进程传递受尺寸、帧率和确认背压限制的画面到业务页面的 canvas。精灵与原有必杀黑幕、特效、弹窗共用 DOM 层级和缩放；不能用浮在页面上方的原生子视图替代。隔离执行与页面合成分别验收，功能事件通过不能代替实际画面的遮挡、透明度和位置验收。
