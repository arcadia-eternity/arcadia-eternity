# 内容包读取边界

生产路径读取已构建或已准备的内容，不直接读取内容项目的 `data/`、`src/` 或 `locales/` 源目录。`base` 与 UGC 使用同一套准备和发布规则。

| 运行场景                 | base package                                                                                                                                          | UGC package                                                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 浏览器离线               | 默认网页环境从随发行物提供的 base npm 包准备；自定义环境由项目依赖树决定，可省略 base                                                                 | 构建时通过 `ARCADIA_WEB_ENVIRONMENT_PROJECT` 的环境安装树准备，与 base 共用 `environment/catalog.json` 和 `environment/runtime.json` |
| 使用服务器发布环境的房间 | 按房间锁定的版本从服务器取公开目录和媒体地址。服务器托管时由服务器执行，玩家托管时双方按该房固定描述准备对应的 `peer-materials`，由选定的玩家宿主执行 | 与 base 共用该房间的版本及材料来源                                                                                                   |
| 使用个人环境的私人约战   | 双方从明确选择的分享文件或 HTTPS 来源取得材料，核对建房时固定的描述                                                                                   | 随同一份个人环境材料准备，由玩家宿主执行。信令服务器只接收固定引用与准备确认                                                         |
| 客户端单机               | 内容定义与战斗材料从桌面内容库中随应用安装的 base npm 包准备                                                                                          | 从桌面内容库安装的 UGC npm 包或用户工作区自建项目准备，与 base 一起由 `prepareNpmProject` 生成会话环境                               |
| 桌面使用服务器发布的环境 | 本机服务器借用桌面工作区的同一已准备项目；远程服务器只使用其发布环境                                                                                  | 与 base 相同；本机不复制第二份内容库，远程不使用本地同名包替代                                                                       |
| 服务端                   | 通过 `prepareShippedEnvironment` 读取随发行物提供的已编译 base 包                                                                                     | 从服务器工作区或启动项目安装树通过 `prepareNpmProject` 准备，并发布给房间                                                            |

桌面本机服务器通过私有工作区桥接采用同一版本，不创建可写副本；桌面使用远程服务器发布的环境时，读取该服务器为房间提供的目录。浏览器页面从生产发行物的 `dist/web` 加载这些入口。

桌面应用的资源索引与内容定义、战斗材料来自同一份已准备内容，不再单独读取 `userData/packs/base`。

用户自建包只以用户工作区项目的可编辑形式维护，依赖按 npm 方式声明。工作区的编辑、文件浏览和外部助手读取源文件；展示与对战读取该包时仍走 npm 依赖树和 `prepareNpmProject` 准备，不从工作区直接读取 `data/`、`src/` 或 `locales/`。
