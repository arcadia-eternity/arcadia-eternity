# 对战界面改造（2026-10-07）

参考 seer2-fight-ui 的圆角暗蓝技能卡、青色弧形高光、银色面板边缘、对称阵容与战场层次，改造当前项目的 Vue 对战页面。原有精灵动画、头像、属性图标、场景背景、技能说明、印记关系和对战操作保留。

## 最终实现

- UI 配色和间距集中在 `battle-theme.css`，面板边框、工具图标、VS、未知头像与 KO 使用原生 SVG；角色与背景沿用原有素材。
- 整张界面使用 1600×900 固定布局；HUD、精灵、日志与按钮共同等比缩放。伤害、命中效果和镜头运动作用于战场。血量使用即时数值与延迟残影；并发飘字有数量上限，并统一清理。
- 普通技能与必杀共用技能卡片。必杀与普通技能使用同一青色按钮轮廓和暖黄色文字，显示名称、类别、属性、威力与怒气，命中及原有说明保留在详情中。独立详情按钮支持触屏和键盘；滚动列表中的详情浮层显示在列表之外。
- 准备页显示两方阵容与实际加载任务进度。必要数据失败提供重试；场景或动画资源失败允许静态形象降级；备用精灵在首发准备后预取。未知阵容继续隐藏。
- 动效提供标准、简化、减少动态三档，并识别系统减少动态偏好。
- 手机、桌面与不同缩放使用同一布局，按可用视口完整容纳整张画面，不按断点重排按钮或裁切。精灵恢复原有 1.1 倍渲染比例。血条空槽与状态面板透明；日志改为 SVG 面板、事件色标和紧凑记录。

## 三行技能卡与文字修正

按最终反馈，技能卡高度保持 108px，左侧显示属性图标与类别，右侧显示名称、威力、怒气三行，普通技能与必杀共用布局。命中信息从按钮中移除，仍保留在详情中及无障碍说明中。威力与怒气统一 15px 字号、19px 行高，数值靠右；长名称允许换行。SVG 负责底色、圆角边缘和弧形高光，内容网格负责排版。

HP/怒气标签随右方镜像，数值用等宽两列围绕固定斜杠对齐，避免不同位数造成偏移。血条空槽仍透明。整体继续共同缩放，精灵与技能消息坐标未改。

## 原版按钮与蓝色必杀

技能按钮改用参考项目 UI_FightSkillBtn 的原始矢量路径，保留圆形属性框、两条分隔线和曲面高光。名称、类别、威力与怒气按原版 UI_FightSkillBrief 的相对坐标放置；按钮继续保持 108px 高度与三行信息，命中仅在详情显示。必杀沿用相同按钮，增加蓝色荧光边缘、名称高亮与八个固定 CSS 粒子。禁用时停用粒子；简化、减少动态和系统减少动态模式保留静态高亮。

## 侧栏和印记尺寸修正

侧栏头像使用 64×64 画布像素，印记使用 36×36 画布像素，层数使用独立的 14px 字号。移除父级对所有图片和 text-sm 的尺寸覆盖，避免详情内容也被缩小。图标继续与整张画布统一缩放。侧栏、印记详情与技能详情使用相同屏幕浮层；修复浮层左右方向定位，按缩放后的触发区域定位并限制在视口内。印记支持点击展开、键盘聚焦及 Escape 关闭。

本轮浮层定位、技能按钮及 Ruffle 启动测试共 8 项通过，修改的 Vue/测试文件 ESLint 通过。

## 队伍溢出、飘字和命中震动修正

侧栏在画布 top=200、bottom=220 的区域中居中，内部列表限制高度并独立滚动，保留所有精灵和选择入口。12 只精灵的布局验证场景在桌面和手机下都没有侵入操作区，最后一只可通过列表滚动访问。

伤害显示按原版恢复 360×160 画布像素背景、64px 数字、40px 减号，治疗和未命中使用明确的画布像素尺寸。浮层宽度由内容决定，锚点始终由 1600×900 场景坐标计算，整张画布只做一次视口缩放。长数字的局部适配保留。

标准动效补回普通命中短震动（3px），暴击或单次超过最大生命四分之一的重击使用 6px，并保留冲击光和背景偏移。震动通过独立镜头容器作用于整张对战界面（状态栏、侧栏、战场、操作区），幅度随统一画布缩放；必杀震动进行时避免覆盖，清理时归零。外来直接伤害同时产生向外击退与回位，使用独立精灵内层避免覆盖换宠和镜像变换。简化和减少动态模式不震动。技能提示、飘字和原有精灵、必杀、KO 动画继续保留。

Ruffle 构建输出从工作区包扫描中排除，锁文件改为实际注册表依赖，避免安装把播放器重新链接到构建输出目录。14 项相关测试、实现文件 ESLint、生产构建通过。当前离线对局的背景资源降级，与精灵 Ruffle 播放器加载是不同路径。

整屏震动与击退的实际浏览器验证：普通技能命中时镜头出现非零位移、目标精灵内层退开；两者结束后都回到 (0, 0)，画布的 translate(-50%, -50%) scale(0.733333) 始终不变。切换动效模式会清理进行中的震动与击退。

受击时序修正：删除普通攻击约 1.67 秒、必杀最多 3 秒的提前命中兜底。震动、击退、飘字和伤害结算等待实际命中事件；素材没有命中标记时以动画完成为兜底，播放器异常时保留完整时长超时。监听器在播放前注册，并在完成、超时和取消时清理。回归测试覆盖延迟命中、另一侧事件、无命中标记和异常超时。

血条修正：HP 与怒气的数字改用参考 SWF 的原始 SVG 字形，保留修饰器数值与颜色。去掉延迟 450ms、再收缩 500ms 的伤害残影；生命条的长度与血量色相用相同的 180ms 线性过渡，不再提前切换低血量色块。透明底轨和左右镜像锚点保留。
怒气数值与斜杠整体上移 1 个画布像素，左右两侧使用相同偏移。17 项相关测试、ESLint 与生产构建通过；浏览器确认补血时长度和颜色共同过渡，左右锚点及 SVG 字形正确。

真实战斗页怒气数字裁切修正：继承的 24px 行高超过 17px 怒气条高度。数值容器固定 16px 行高，修饰器包装改为 flex 对齐，SVG 去掉基线下沉；色条裁切移至独立 visual 层，数字置于裁切层之外。真实对战页两侧各 6 个 SVG 字形完整显示，3 项血条回归测试与构建通过。
