# 对战界面改造（2026-10-07）

参考 seer2-fight-ui 的圆角暗蓝技能卡、青色弧形高光、银色面板边缘、对称阵容与战场层次，改造当前项目的 Vue 对战页面。原有精灵动画、头像、属性图标、场景背景、技能说明、印记关系和对战操作保留。

## 最终实现

- UI 配色和间距集中在 `battle-theme.css`，面板边框、工具图标、VS、未知头像与 KO 使用原生 SVG；角色与背景沿用原有素材。
- 整张界面使用 1600×900 固定布局；HUD、精灵、日志与按钮共同等比缩放。伤害、命中效果和镜头运动作用于战场。血量使用即时数值与延迟残影；并发飘字有数量上限，并统一清理。
- 普通技能与必杀共用技能卡片。必杀与普通技能使用同一青色按钮轮廓和暖黄色文字，显示名称、类别、属性、威力与怒气，命中及原有说明保留在详情中。独立详情按钮支持触屏和键盘；滚动列表中的详情浮层显示在列表之外。
- 准备页显示两方阵容与实际加载任务进度。必要数据失败提供重试；场景或动画资源失败允许静态形象降级；备用精灵在首发准备后预取。未知阵容继续隐藏。
- 动效提供标准、简化、减少动态三档，并识别系统减少动态偏好。
- 手机、桌面与不同缩放使用同一布局，按可用视口完整容纳整张画面，不按断点重排按钮或裁切。精灵恢复原有 1.1 倍渲染比例。血条空槽与状态面板透明；日志改为 SVG 面板、事件色标和紧凑记录。

## 验证及边界

- 前端生产构建通过，修改的实现文件 ESLint 与差异空白检查通过。
- 对战组件、动画管理、资源缓存与准备流程的相关测试共 111 项通过（107 项对战回归与 4 项统一缩放测试）。
- 浏览器实际验证：首发加载、普通攻击、伤害与怒气更新、换宠、必杀解锁与播放、击倒后的换宠入口、手机布局。
- 全量前端测试：143 项通过，2 项数据编辑器 YAML 往返测试超时，不能报告全量测试通过。
- 全局类型检查仍在未修改的数据编辑器、P2P、对战 store 等文件报错；本次修改的实现文件未出现类型错误。内核包声明构建也存在原有接口联合类型问题。
- 在线真人对战、桌面端资源下载路径仍需有服务连接的环境验证；不把本地人机验证外推为这些路径已通过。

## 原版质感对齐（第二轮）

- 实际对照参考演示：`https://ui.733702.xyz/demo/demo.html`，参考源码固定到 `1c9d524e89b367fd5bc1d7fc2db1d55da0ad9218`。
- 技能按钮与底部面板按参考 Flash 的材质、颜色和弧形高光重新绘制 SVG，取消不适合当前完整信息的固定分隔线。来源及符号编号记录在 `packages/web-ui/src/assets/battle/README.md`。
- 加载页网格雷达用 SVG pattern 和圆形路径重绘，背景体积由原始导出约 142 KB 降为约 1 KB；增加受减少动态偏好控制的雷达扫描。进度继续使用实际任务数据。
- 保留完整五张技能卡和 1600×900 统一缩放，不照搬原版省略信息的紧凑必杀入口。血条保留透明空槽，填充改为原版明绿/红橙渐变；状态区不再增加覆盖背景的面板。
- 日志沿用真实记录与自动滚动，面板边缘改为银色倒角；按钮、回合牌及文字颜色统一为原版青色/暖黄体系。精灵和技能消息栏坐标未改。
- 本轮是视觉资产和样式对齐，未声称参考项目所有 Flash 动画和像素位置已完全移植。

本轮验证：最终生产构建通过，修改的 Vue 实现文件 ESLint 通过，准备流程与布局 store 两个测试文件的 8 项测试通过。浏览器验证了技能释放后的血量、怒气和日志更新；桌面与 390×844 视口中，五张技能卡均完整位于画布内，归一化位置相同，四个血条/怒气空槽均为透明。当前离线测试出现连接初始化提示与首发动画降级，截图中的静态角色不是完整 SWF 动画验证。

## 三行技能卡与文字修正

按最终反馈，技能卡高度保持 108px，左侧显示属性图标与类别，右侧显示名称、威力、怒气三行，普通技能与必杀共用布局。命中信息从按钮中移除，仍保留在详情中及无障碍说明中。威力与怒气统一 15px 字号、19px 行高，数值靠右；长名称允许换行。SVG 负责底色、圆角边缘和弧形高光，内容网格负责排版。

HP/怒气标签随右方镜像，数值用等宽两列围绕固定斜杠对齐，避免不同位数造成偏移。血条空槽仍透明。整体继续共同缩放，精灵与技能消息坐标未改。

## 原版按钮与蓝色必杀

技能按钮改用参考项目 UI_FightSkillBtn 的原始矢量路径，保留圆形属性框、两条分隔线和曲面高光。名称、类别、威力与怒气按原版 UI_FightSkillBrief 的相对坐标放置；按钮继续保持 108px 高度与三行信息，命中仅在详情显示。必杀沿用相同按钮，增加蓝色荧光边缘、名称高亮与八个固定 CSS 粒子。禁用时停用粒子；简化、减少动态和系统减少动态模式保留静态高亮。
